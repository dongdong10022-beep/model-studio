# Model Studio · 模特经纪网站

一个简单大气的模特展示网站（含在线客服与运营后台）。支持中国籍、乌克兰籍、欧美籍模特展示，自动标记拍摄价格；乌克兰 / 欧美籍模特资料需访问密码；内置实时客服系统。

## 功能

- **模特展示**：中国籍、乌克兰籍、欧美籍模特卡片，含头像、国籍、年龄、身高、三围、擅长风格、拍摄价格、个人简介。
- **访问密码**：乌克兰籍 / 欧美籍模特默认「需密码」展示，访客输入正确访问码后解锁完整资料。
- **在线客服**：右下角浮动入口，访客可随时发文字、图片、位置，也可选择常用快捷咨询语。
- **运营后台**（`/admin.html`）：
  - 实时查看在线访客、会话并随时回复（文字 / 图片）。
  - 自动记录访客 **IP 地址、手机型号 / 设备、操作系统、浏览器、在线状态、访问时间**。
  - 可查看访客上报的 **位置**（一键打开地图），或主动「请求位置」让访客授权。
  - 模特资料管理（改价格 / 简介 / 锁定状态）。
  - 系统设置（改访问密码、管理员账号密码）。

## 运行

```bash
npm install          # 首次
npm start            # 或 node server.js
```

启动后：

- 前台展示页：<http://localhost:3000/>
- 管理后台：<http://localhost:3000/admin.html>

## 访问方式

- 本机：http://localhost:3000/
- 局域网（本机 IP 192.168.0.101）：http://192.168.0.101:3000/（已添加防火墙入站规则放行 3000）
- 公网：使用 `tunnel.bat` 启动 SSH 隧道（serveo），运行后输出新的公网 HTTPS 地址。隧道断线或重启后地址会变，需重新运行。
  - 注意：公网地址由 serveo 随机分配，重启后变化；如需永久固定域名，需绑定自有域名 + Cloudflare 或升级 serveo Pro / 部署到云主机。

## 启停

- 启动网站服务：`start.bat`（或 `npm start`）
- 启动公网隧道：`tunnel.bat`（需先运行 start.bat）

## 目录结构

```
project/
├─ server.js              # Express + WebSocket 后端
├─ package.json
├─ data/
│  ├─ config.json         # 站点/管理员/访问密码
│  ├─ models.json         # 模特资料
│  ├─ visitors.json       # 访客（IP/设备/位置）
│  ├─ messages/           # 会话记录
│  └─ uploads/            # 聊天图片
└─ public/
   ├─ index.html          # 前台
   ├─ admin.html          # 后台
   ├─ css/  js/  img/     # 样式脚本与模特头像(SVG)
```

## 说明

- 定位功能依赖浏览器 Geolocation：在 `localhost` 或 `https` 下可直接授权；通过局域网 IP（`http://192.168.x.x:3000`）访问时，部分浏览器会要求 HTTPS 才能定位。
- 设备 / 手机型号由 User-Agent 推断，可能不精确。
- 后台默认前端会话用 WebSocket 实时通信，断线会自动重连。
